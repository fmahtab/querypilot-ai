# RetailStar — Returns Policy

## Purpose

This document defines RetailStar's standards for customer returns and refunds across physical stores, e-commerce, and BOPIS orders. It establishes eligibility rules, restocking procedures, and reporting definitions — with category-specific guidance for art and craft products where opened consumables, cut-to-order fabric, project kits, and specialty tools require different handling.

All store associates, customer service teams, and category managers should follow these guidelines when processing returns and analyzing return rate performance.

---

## Scope

This policy applies to:

- In-store returns at any RetailStar location
- E-commerce ship-to-home return shipments
- BOPIS order returns (processed at the originating pickup store or via mail for online-initiated returns)
- Exchanges and partial order returns

Returns are tracked at the **SKU × store × order** level and linked to the original sales channel for reporting.

---

## Standard Return Window

| Channel | Return Window | Condition Required |
|---------|---------------|-------------------|
| **Physical store** | 30 days from purchase date | Item in resalable condition with receipt or proof of purchase |
| **E-commerce** | 30 days from delivery date | Item unused and in original packaging where applicable |
| **BOPIS** | 30 days from pickup date | Same as physical store |

Returns initiated after the return window are declined unless approved by a store manager for documented product defect or RetailStar error.

---

## General Eligibility Rules

A return is **eligible** when all of the following are true:

1. The item is within the standard return window.
2. The item meets category-specific condition requirements (see below).
3. The item is not listed as non-returnable.
4. Proof of purchase is provided (receipt, order confirmation, or loyalty account lookup).

A return is **ineligible** when:

- The item has been used, opened, or altered beyond inspection (category exceptions apply).
- The item is a final-sale, clearance, or post-season markdown seasonal kit.
- The item is cut-to-order fabric that has been cut from the bolt.
- The item is a custom-ordered or special-order SKU.
- The return window has expired without manager override.

## Category-Specific Return Rules

### Fine Art Supplies

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Canvas, paper, substrates (unopened) | Yes | Original packaging intact |
| Tube paints, inks (unopened) | Yes | Seal unbroken |
| Opened paints, inks, mediums | No | Consumable — cannot verify remaining volume or contamination |
| Brushes, palette knives (unused) | Yes | Original packaging or clearly unused |
| Brushes (used) | No | Hygiene and wear cannot be verified |

### Yarn & Needlecraft

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Yarn skeins (unused, labels intact) | Yes | No signs of use, winding, or odor |
| Opened or partially used yarn | No | Cannot confirm condition or length |
| Crochet hooks, knitting needles (unused) | Yes | Original packaging |
| Cross-stitch / embroidery kits (unopened) | Yes | Shrink wrap or seal intact |
| Opened kits | No | Components may be missing or used |

### Fabric & Sewing

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Fat quarters and precut bundles (unused) | Yes | Original packaging, no cutting or washing |
| Fabric by the yard (uncut bolt return) | Yes | Full uncut bolt only; must match original SKU |
| Cut-to-order fabric | No | Customized at time of purchase — see Inventory Policy |
| Thread, notions (unopened) | Yes | Factory seal intact |
| Opened thread spools | No | Consumable |

### Paper & Scrapbooking

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Cardstock packs, paper pads (unused) | Yes | No sheets removed |
| Stamps, ink pads (unused) | Yes | Unopened or clearly unused |
| Used ink pads, partially used paper | No | Consumable |
| Die-cutting dies, embossing folders (unused) | Yes | Original packaging |

### Jewelry & Beading

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Beads, findings (unopened packages) | Yes | Original packaging intact |
| Opened bead assortments | No | Small components cannot be verified complete |
| Pliers and tools (unused) | Yes | Original packaging, no wear |

### Kids & Classroom Crafts

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Classroom packs (unopened) | Yes | Factory seal intact |
| Opened marker sets, glue, paint | No | Consumable and hygiene |
| Safety scissors, unused craft sets | Yes | Original packaging |

### Clay & Modeling

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Unopened polymer clay, air-dry clay | Yes | Original packaging |
| Opened clay packages | No | Exposure to air affects product quality |
| Tools and molds (unused) | Yes | Original packaging |

### Home Décor & DIY / Project Kits

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Unopened project kits | Yes | All components sealed inside |
| Opened project kits | No | Components may be missing, mixed, or used |
| Wreath forms, wood blanks (unused) | Yes | No modification or assembly |
| Candle-making kits (unopened) | Yes | Wax and fragrance oils must be sealed |

Project kits have historically higher return rates than individual supplies. Opened kits are the most common driver of category-level return rate elevation.

### Craft Tools & Storage

| Item Type | Returnable | Conditions |
|-----------|------------|------------|
| Tools (unused, in packaging) | Yes | No wear, damage, or missing parts |
| Used tools | No | Wear and functionality cannot be verified |
| Storage bins and organizers (unused) | Yes | Original packaging |

---

## Non-Returnable Items

The following are **never returnable** regardless of condition or channel:

- Cut-to-order fabric sold by the yard
- Opened consumables (paint, glue, ink, clay, thread, yarn partially used)
- Opened project kits and seasonal kits after peak markdown
- Final-sale and clearance items (marked at point of sale)
- Custom or special-order items
- Gift cards and workshop class fees
- Items returned without proof of purchase (exchange for store credit at manager discretion only)

---

## Return Processing by Channel

### In-store returns

1. Customer presents item and proof of purchase at any RetailStar store.
2. Associate verifies eligibility against this policy.
3. Refund issued to original payment method, or store credit if original method unavailable.
4. Return logged against the original store and SKU in the central system.

### E-commerce returns

1. Customer initiates return through RetailStar.com within the return window.
2. Return shipping label provided for eligible items (customer pays return shipping unless item is defective).
3. Refund processed within **5 business days** of the returned item being received and inspected at the distribution center.
4. Return logged against the e-commerce channel and fulfilling location.

### BOPIS returns

1. Customer may return at the pickup store or any RetailStar location with proof of purchase.
2. Refund issued to original payment method.
3. If item is restockable, inventory is restored at the pickup store.
4. Return logged against the BOPIS channel and pickup store.

---

## Refund Methods

| Original Payment | Refund Method |
|-----------------|---------------|
| Credit / debit card | Refund to original card (3–5 business days) |
| Cash | Cash refund (in-store only) |
| Gift card | Store credit or gift card reload |
| PayPal / digital wallet | Refund to original account |

Partial order returns refund only the returned SKU line item plus applicable tax. Shipping charges are non-refundable unless the return is due to RetailStar error or product defect.

---

## Restocking Rules

When a return is approved, restocking depends on item condition and category:

| Outcome | Restocking Action |
|---------|-------------------|
| Unopened, resalable item | Returned to store or warehouse inventory; counted as restocked unit |
| Opened consumable (declined return) | Not applicable — return denied |
| Defective item | Quarantined; not restocked; supplier claim initiated if applicable |
| Cut-to-order fabric (full bolt) | Restocked only if bolt is uncut and matches original SKU |

Restocked units reduce the return count in net sales reporting but are tracked separately in return reason codes for analysis.

---

## Return Rate Definitions

RetailStar tracks return rate at the category, SKU, store, and channel level.

### Unit return rate

```
return_rate = (returned_units / sold_units) × 100
```

### Revenue return rate

```
revenue_return_rate = (returned_revenue / gross_revenue) × 100
```

### Net revenue (after returns)

```
net_revenue = gross_revenue − returned_revenue
```

Leadership uses **net revenue** — not gross sales alone — when evaluating category and store performance.

---

## Return Rate Thresholds

Category managers monitor return rates against the following internal benchmarks:

| Category | Target Return Rate | Elevated (Review Required) |
|----------|-------------------|---------------------------|
| Fine Art Supplies | ≤ 4% | > 6% |
| Yarn & Needlecraft | ≤ 5% | > 8% |
| Fabric & Sewing | ≤ 3% | > 5% |
| Paper & Scrapbooking | ≤ 4% | > 6% |
| Jewelry & Beading | ≤ 5% | > 7% |
| Kids & Classroom Crafts | ≤ 3% | > 5% |
| Clay & Modeling | ≤ 5% | > 8% |
| Home Décor & DIY / Project Kits | ≤ 8% | > 12% |
| Craft Tools & Storage | ≤ 3% | > 5% |

When a category exceeds the elevated threshold, the category manager must document root cause (e.g., incomplete kit contents, misleading product description, quality defect) and submit a corrective action plan within 14 days.

## Common Return Reason Codes

All returns must be logged with one of the following reason codes:

| Code | Reason | Typical Categories |
|------|--------|--------------------|
| **DEFECT** | Product defect or damage | All |
| **WRONG_ITEM** | Incorrect item shipped or sold | E-commerce, BOPIS |
| **NOT_AS_DESCRIBED** | Product did not match description or image | Project kits, tools |
| **CHANGED_MIND** | Customer no longer wants item (eligible items only) | All |
| **DUPLICATE** | Customer purchased duplicate in error | Consumables, yarn |
| **SIZE_COLOR** | Wrong size, color, or weight selected | Yarn, fabric, beads |
| **MISSING_PARTS** | Kit missing components | Project kits |
| **RETAILSTAR_ERROR** | Pricing, fulfillment, or policy error by staff | All |

---

## Defective Product Handling

1. Customer may return defective items within **60 days** (extended window) with proof of purchase.
2. Defective items are not restocked.
3. Supplier claim is initiated for recurring defects on the same SKU.
4. RetailStar pays return shipping for confirmed defective e-commerce orders.

---

## Reporting & Review Cadence

| Report | Audience | Frequency |
|--------|----------|-----------|
| Return rate by category | Category managers | Weekly |
| Return rate by SKU (top 20 elevated) | Category managers, merchandising | Weekly |
| Return reason code summary | Category managers, leadership | Weekly |
| Return rate by store and channel | Regional ops, leadership | Monthly |
| Defect and supplier claim log | Merchandising, leadership | Monthly |

Leadership reviews return performance alongside sales and inventory metrics on a weekly and quarterly basis, as defined in the Company Overview. Return rate reduction is a stated business goal — particularly for project kits, specialty tools, and fabric categories.
